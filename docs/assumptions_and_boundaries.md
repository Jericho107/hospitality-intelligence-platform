# Assumptions and Boundaries

## Data

All public datasets in this project will be synthetic.

The project will not use real guest names, employee identities, payment details, reservation records or client information.

## Business

The case is designed to model realistic hospitality economics, not to represent a specific hotel's actual performance.

Any benchmark, threshold or standard-cost assumption introduced later must be labelled as synthetic, external or scenario-specific.

## Causality

Descriptive and diagnostic analysis can identify associations and plausible drivers.

It cannot automatically prove causal impact.

Recommendations must distinguish:

- observed relationship;
- operational hypothesis;
- proposed intervention;
- measured post-action result.

## Forecasting

Forecast performance in synthetic data is not production performance.

The final repository must state data horizon, split logic, baseline, metric and stability limitations.

## Commercial impact

Modeled savings or margin upside are estimates unless a real intervention is observed.

The repository will not convert scenario estimates into claims of realized client impact.
