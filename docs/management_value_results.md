# Management Opportunity Results — Synthetic Benchmark

## Evidence run

GitHub Actions run #34 evaluated the management opportunity model after all Phase 1–6 gates passed.

These figures are synthetic modeled opportunity estimates. They are not realized savings, client ROI or production forecasts.

## Analysis scope

- property: synthetic leisure resort P002;
- analysis window: final 20 days;
- baseline window: prior 20 days;
- focus: beverage purchase price, beverage waste and F&B overtime premium;
- recovery scenarios: 25% / 50% / 75%.

## Healthy control

Observed exposure:

- purchase price: 147.11;
- waste: 37.17;
- overtime premium: 91.09.

Modeled recoverable opportunity:

- conservative: 68.84;
- base: 137.69;
- stretch: 206.53.

## Margin-leakage scenario

Observed exposure:

- purchase price: 3,429.78;
- waste: 1,584.99;
- overtime premium: 1,798.33.

Modeled recoverable opportunity:

- conservative: 1,703.28;
- base: 3,406.55;
- stretch: 5,109.83.

The base modeled opportunity is approximately 24.7 times the healthy control.

## Interpretation

The model passes a narrow synthetic truth test:

- each controlled leakage exposure is higher than healthy;
- total modeled opportunity is materially higher than healthy;
- the same calculation logic is applied to both scenarios.

The model does not establish causal savings.

A real consulting engagement would require:

1. intervention approval;
2. action implementation;
3. post-action observation;
4. service-quality and volume controls;
5. attribution analysis;
6. realized-value measurement.

Until those steps exist, these figures remain opportunity estimates.
